# Calculator App

A simple and responsive Calculator built with **HTML**, **CSS**, and **JavaScript** to demonstrate my understanding of core JavaScript concepts and DOM manipulation.

## Features

- Basic arithmetic operations: `+`, `-`, `×`, `÷`
- Real-time input and result display
- Clear (`C`) and delete (`⌫`) functionality
- Responsive design for mobile and desktop

## Technologies Used

- **HTML** – for structure  
- **CSS** – for styling and layout  
- **JavaScript** – for logic and interactivity  

## Purpose

This project is part of my journey to become a full-stack developer. It serves as a demonstration of my ability to:

- Work with JavaScript events and functions
- Manipulate the DOM
- Handle user input and edge cases
- Write clean and modular code
